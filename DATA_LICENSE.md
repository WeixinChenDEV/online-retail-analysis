# Dataset attribution

Chen, D. (2015). *Online Retail* [Dataset]. UCI Machine Learning Repository.
DOI: https://doi.org/10.24432/C5BW33
Source: https://archive.ics.uci.edu/dataset/352/online+retail
License: [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/).

Prepared CSVs and analysis outputs are derived from this dataset. Changes include
classification of positive sales and negative-quantity credits; exclusion of
nonpositive-price entries; line amount rounding; addition of dimensions, order
aggregates, RFM snapshot and cohort activity. Exact repeated source records are
retained because no transaction-line identifier establishes that they are errors.
These transformations and findings are independent of, and not endorsed by, UCI
or the dataset creator.
