# 用这份项目补齐求职能力

## 先理解，再放进简历

这是一份通过 AI 辅助生成的项目底稿。你需要在 Power BI Desktop 中亲自刷新、
核对关键数字、测试交互，并能解释每一项方法后，再作为个人作品用于面试。
尚未完成 Desktop 验证时，不要声称已经上线或获得业务成果。

## 建议学习顺序

1. 看 README 和 methodology，理解数据来源、历史时间范围、分析问题与指标口径。
2. 打开 `analyze.py`，理解未知客户、冲销、异常价格、订单粒度、RFM 与队列处理。
3. 用 SQLite 执行 `sql/analysis.sql`，独立确认销售、订单、复购和分群结果。
4. 看 model.bim 的表、关系和 Power Query，理解两个事实表与单向维度筛选。
5. 看 measures.dax，逐个理解 CALCULATE、SUM、COUNTROWS、DISTINCTCOUNT、DIVIDE、VALUES 与 FILTER。
6. 打开 Desktop，执行 docs/打开项目.md 的验证，再修改一项分析或交互并记录原因。

## 需要能回答的面试问题

- 为什么毛销售、冲销和净记录销售要分开？为什么不能把净销售称为利润？
- 为什么 CustomerID 缺失时仍保留销售金额，但不能计算客户复购？
- 为什么原始重复行没有直接删除？删除与保留各有什么风险？
- 为什么订单有自己的事实表？为什么商品筛选不会重新定义订单卡片？
- RFM 如何处理相同频次？为什么某个分群不等于真实流失预测？
- 2011 年 12 月为何不纳入完整月份比较？未观察到的 cohort cell 为何不能填零？
- 65.6% 的复购客户占比与矩阵里的月度重复购买活跃度有什么区别？
- 如何证明筛选后的仪表盘数据与 SQL 一致？
- 哪个业务建议有证据，哪部分仍是待验证的假设？
