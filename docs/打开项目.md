# 如何打开与完成 Desktop 验证

这份交付包含真正的 Power BI 项目源文件 PBIP、PBIR 报告和语义模型。
已在本机 Power BI Desktop 中打开四页报表，数据校验记录见 `validation.json`。

1. 安装或打开标准版 Power BI Desktop（不是 Report Server 专用版）。
2. 在项目根目录运行 `python scripts/configure_local.py`，设置当前电脑的 CSV 路径。
   也可以在 Desktop 的 Transform data → Edit parameters 中将 `DataFolder`
   设置成项目下 `data/processed` 的绝对路径。
3. 打开 `powerbi/RetailInsights.pbip`；也可以打开报告目录的 `definition.pbir`。
4. 初次打开时，先点击“应用更改”（如有），再点击 Refresh 导入数据；GitHub 不附带 Desktop 本地缓存。
   如提示关系需要刷新，先点击该提示的“立即刷新”。查询第一次载入时若提示循环引用，
   关闭提示后点击“应用更改”，使 DataFolder 参数与表定义一起载入，再刷新。
5. 报表已附带配色；也可以在主题菜单中选择 `assets/retail-theme.json`。
6. 全部取消筛选后核对：Gross Sales £10,666,684.54；Recorded Credits £896,812.49；
   Net Recorded Sales £9,769,872.05；Sales Orders 19,960；购买客户 4,338。
7. 按月份和国家筛选经营页，检查卡片、趋势与表格一致；商品页选择商品类型并核对明细。
   客户页是固定 RFM 快照，队列页仅按自己的 Cohort 筛选，不应误认为响应经营页的筛选。
8. 检查标题、图表标签、滚动、空值、矩阵及字体；确认没有错误图表或遮挡。
9. 可 Save As 为 PBIX，把已导入数据保存为单文件；原生界面截图位于 `assets/screenshots`。

`configure_local.py` 会修改 model.bim 中的路径参数。提交 GitHub 时请将个人路径
运行 `python scripts/configure_local.py --portable` 恢复为通用占位路径；
不要提交缓存、访问凭据或此目录以外的简历文件。

数据是历史案例，不代表当前电商市场。GitHub 仓库用于公开源码与报告；
公开的在线 Power BI 交互链接需要另外的 Power BI Service 发布流程。
